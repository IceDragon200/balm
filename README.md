# Balm

A standard library for love2d games.

Balm's primary focus is to provide basic primitives for use in lua or love2d specific games.

## Structure

* `m/*` contains modules, these are simple tables that contain functions that often operate on basic data types, such as strings, numbers, and tables.
* `p/*` contains persistence related modules and structures, these can be used to serialize data for any purpose
* `s/*` contains a handful of data structures
* `u/*` contains utilities which don't quite fit into the module category
